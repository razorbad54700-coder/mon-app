SERVEUR MonApp
==============
1) Installe Node.js (version LTS) : https://nodejs.org
2) Double-clique sur  lancer-serveur.bat
   -> une fenetre noire s'ouvre et affiche ton CODE D'INSCRIPTION.
   -> laisse-la ouverte tant que tu veux que le serveur soit allume.
3) Tes donnees sont dans le dossier "data" (a cote de ce fichier) :
   - data.json        : comptes, serveurs, salons
   - config.json      : ton code d'inscription (modifiable)
   - messages.json    : tous les messages
   - images/          : les images envoyees dans le chat
   - sauvegardes/     : une copie automatique a chaque demarrage
   Tu peux deplacer tout le dossier "serveur" sur ton disque F:.
4) Dans l'appli, a l'ecran de connexion, mets l'adresse du serveur :
   - sur ton PC :     http://localhost:3000
   - meme reseau wifi : http://IP-DE-TON-PC:3000
   - amis a distance : l'adresse donnee par ton tunnel (voir le guide)

VOCAL
-----
La voix passe directement entre les joueurs. Si certains amis ne s'entendent pas (reseau tres restrictif),
il faut un serveur TURN : ajoute dans data/config.json la ligne
  "turn": { "urls": "turn:adresse:3478", "username": "...", "credential": "..." }


=== CONNEXION AVEC GOOGLE (facultatif) ===
Sans cette étape, le bouton « Continuer avec Google » dit simplement que ce n'est pas activé.
1. Va sur https://console.cloud.google.com et crée un projet (gratuit).
2. Menu « API et services » > « Écran de consentement OAuth » : type « Externe », donne un nom à l'appli,
   mets ton e-mail. Ajoute ton adresse Gmail (et celles de tes amis) comme « utilisateurs test ».
3. « Identifiants » > « Créer des identifiants » > « ID client OAuth » > type « Application Web ».
   Dans « Origines JavaScript autorisées », ajoute l'adresse de ton serveur, par exemple http://localhost:3000
   (Google n'accepte que localhost ou une adresse en https : pour tes amis il faudra le tunnel de la phase 10).
4. Copie l'ID client (qui finit par .apps.googleusercontent.com) et ajoute-le dans serveur/data/config.json :
     "googleClientId": "TON-ID.apps.googleusercontent.com"
   (sans oublier la virgule avec la ligne du dessus). Relance le serveur.
